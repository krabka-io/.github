# .github

Organization-wide defaults and profile for [krabka-io](https://github.com/krabka-io).

- [`profile/README.md`](profile/README.md) — the README displayed on the organization's GitHub profile page.
- Any community health files added here (issue templates, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, etc.) act as defaults for repositories in the organization that don't define their own.
